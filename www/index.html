📄 File format

Accepted: .xlsx or .csv (first sheet only)

Either layout works:
• Club name on its own row, then rows of Carry + Side below it
• One row per shot: Club, Carry, Side

Column rules:
• Carry must be in meters, between 10–400
• Side accepts a plain number or R/L suffix (e.g. 5R, 3.2L)

📍 Elevation points

Values are your phone's GPS altitude reading (meters above sea level) at each recorded spot — not relative to the tee or green. Delete any that look dramatically wrong (bad GPS fix); this only affects elevation-adjusted carry, not the tee or green position.
